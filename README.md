# KRISHNA — THE SERIES

A cinematic, streaming-inspired portfolio for **Krishna Sidhvi Nekkanti**: Data Analyst & Data Engineer.
Every section is an episode, every project is an Original, and the whole portfolio plays like an interactive Netflix series.

> A personal portfolio with a fictional streaming-platform look. It is not affiliated with Netflix or any other streaming service and uses none of their proprietary marks.

---

## Live Features & Structure

- **Opening Cinematic Sequence**: Letterbox animation, studio title card (*A NEKKANTI ORIGINAL*), projector light flicker, stylized 3D avatar reveal, and magnetic Play button.
- **Audience Profile Selector**: *"Who's watching?"* featuring 4 role-tailored viewing profiles:
  - **Krishna (Main)**: The full series in sequential narrative order.
  - **Recruiter**: Executive resume, verified achievements, and skills first.
  - **Developer**: Projects, architecture topologies, and GitHub first.
  - **Creative**: Story arc, highlights, and journey first.
- **Billboard Hero**: Parallax 3D avatar with red rim lighting, particle atmosphere, and live stat chips (+30% Reliability, -50% Anomalies).
- **Interactive Highlight Reel ("Play Intro")**: Full-screen cinematic slides showcasing enterprise impact across Global Payments, Amazon, and Vanguard.
- **Continue Watching Rail**: Section cards with live progress bars tracking real scroll engagement.
- **The Pilot (About Me)**: Starring card with 3D avatar, verified education (UMBC M.S. Data Science), and core specializations.
- **My Journey (6 Seasons)**: Full chronological career episodes from Amity University through UMBC Graduate Research, Vanguard, Amazon, Global Payments, to Modern Data Lakehouses & GenAI.
- **Originals (6 Production Systems)**: Pinned horizontal scrolling gallery on desktop and swipe rail on mobile featuring interactive architecture modals, metrics, and repository links.
- **Top Picks**: Top 10 career highlights from the resume displayed as Netflix-style numbered cards.
- **Skills with Factual Evidence**: Interactive technology categories with real-time hover cards proving exact production usage.
- **Top Moments & Certifications**: Golden laurel award posters for the 6 distinct milestones alongside a horizontal rail for 5 verified credentials (AWS Associate Data Engineer, Databricks GenAI, LangChain, Hugging Face, LinkedIn).
- **The Full Story / Resume**: Embedded interactive resume sheet and full-screen PDF modal with direct download.
- **Final Episode CTA**: *"TO BE CONTINUED..."* with direct contact actions for LinkedIn, GitHub, and email collaboration.

## Tech Stack

- **Framework**: React 18 & TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS 4 & Vanilla CSS Design Tokens
- **Animations**: Framer Motion 11
- **Smooth Scrolling**: Lenis

---

## Run Locally

Requires **Node.js 18+**.

```bash
npm install
npm run dev
```

Open the local server URL (usually `http://localhost:5173`).

### Production Build

```bash
npm run build
npm run preview
```
